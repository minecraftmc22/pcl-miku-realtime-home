# PCL Miku 实时主页

这个小服务会动态生成 PCL 能读取的 `Custom.xaml`：

- API 区显示 Mojang 版本清单、玩家档案、会话服务的实时状态、响应耗时和关键结果。
- 新闻区抓取 Minecraft 官方新闻页，直接把标题显示在 PCL 卡片里。
- 点击主页中的“刷新实时数据”会重新请求接口并刷新主页。
- 服务不需要 Flask 或其他第三方 Python 包。

## 启动

在本文件所在文件夹打开终端，运行：

```powershell
py .\realtime_home_server.py
```

然后把 PCL 的联网自定义主页地址设置为：

```text
http://127.0.0.1:8765/Custom.xaml
```

服务运行时，PCL 才能获取实时数据。关闭终端后，主页会回到 PCL 的缓存内容。

## 说明

本地运行只适合自己使用。如果要让其他设备访问，需要把服务部署到公网服务器，并把 `--host` 改为 `0.0.0.0`，再使用服务器的公网地址配置 PCL。服务请求的数据源为 Mojang 官方 API 与 Minecraft 官方新闻页。
